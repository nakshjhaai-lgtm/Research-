# Docs

Five documents, in the order most people want them.

| File | What it is | Read it if |
|---|---|---|
| [overview.md](overview.md) | the argument, start to finish, in plain language | you want to know what was found and why it matters |
| [technical-report.md](technical-report.md) | the full write-up: every table, every check, every bug | you want to reproduce or review a specific number |
| [results-index.md](results-index.md) | one entry per file in `results/`, with column meanings | you are looking up what a column is |
| [reproduction.md](reproduction.md) | how to run it, including the CARA and Octave path | you are actually going to run something |
| [handoff.md](handoff.md) | state of play: done, open, and the traps already stepped in | you intend to continue the work |
| [glossary.md](glossary.md) | Pc, CDM, TCA, HBR, LRP, F2 and the rest | a term is unfamiliar |
| [licensing.md](licensing.md) | data, third-party terms, and the missing licence on the code | you want to reuse any of it |
| [file-map.md](file-map.md) | what moved and what was renamed in this upload | you are comparing against the original archive |

The `notes/` directory holds the working notes written while the work was being
done, one file per layer plus the roadmap. They are rougher than these documents
and are left as they were written, cross-references and all. Start with
[`notes/ROADMAP.md`](../notes/ROADMAP.md) if you want the plan of record, and
[`notes/learning_path.md`](../notes/learning_path.md) if you want the physics
background worked out from first principles.
